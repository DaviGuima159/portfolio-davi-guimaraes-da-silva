# 🎯 QR Forge — Gerador de QR Codes Personalizados

## 📝 Descrição do Projeto

O QR Forge é um projeto desenvolvido com o objetivo de criar QR Codes personalizados de maneira prática, moderna e intuitiva.

A aplicação foi construída buscando unir funcionalidade, design visual e facilidade de utilização, permitindo gerar QR Codes para diferentes tipos de compartilhamento digital.

O sistema foi desenvolvido como prática acadêmica voltada para desenvolvimento de software, organização de interface e aplicação de conceitos de automação.
