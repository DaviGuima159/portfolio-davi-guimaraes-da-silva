# ⚔️ Batalha de Modelos & Engenharia de Prompt (XML)

## 📝 Descrição do Projeto

Este projeto foi desenvolvido com foco em Engenharia de Prompt aplicada à Inteligência Artificial generativa, utilizando um protocolo estruturado em XML para geração automática de uma página HTML5 Single Page com CSS3 interno.

A atividade teve como principal objetivo analisar como diferentes modelos de Inteligência Artificial interpretam prompts estruturados, avaliando precisão, criatividade, qualidade do código gerado, quantidade de tokens utilizados e capacidade de compreensão semântica.

O experimento foi realizado utilizando múltiplas IAs generativas, permitindo comparar comportamento, eficiência e qualidade das respostas produzidas por cada modelo.

---

## 🎯 Objetivo da Atividade

Construir um prompt estruturado em XML capaz de orientar diferentes modelos de IA na geração de uma aplicação web moderna utilizando:

- HTML5
- CSS3 interno
- Layout responsivo
- Estrutura semântica
- Organização visual moderna

O prompt também possuía restrições técnicas específicas e critérios obrigatórios relacionados à responsividade, design e estrutura do código.

---

## 🧠 Resultados Obtidos

Os testes demonstraram diferenças significativas entre os modelos analisados.

O modelo DeepSeek apresentou excelente interpretação estrutural do XML e alto nível de precisão técnica.

Já o Qwen se destacou pela eficiência no consumo de tokens, utilizando quantidade muito inferior em comparação aos demais modelos.

O Claude apresentou excelente desempenho em projetos mais complexos, enquanto o ChatGPT demonstrou grande eficiência para prototipagem rápida.

A IA Maritaca apresentou desempenho inferior nos critérios de criatividade, precisão e estruturação do código.

## 🔍 Reflexão Crítica

O experimento demonstrou como diferentes modelos de IA possuem comportamentos distintos mesmo utilizando exatamente o mesmo prompt estruturado.

Também foi possível compreender a importância da Engenharia de Prompt na construção de instruções claras, organizadas e semanticamente eficientes para Inteligência Artificial.

Além disso, o projeto permitiu observar diferenças relevantes entre:
- criatividade;
- interpretação contextual;
- otimização de tokens;
- estruturação de código;
- robustez técnica.
