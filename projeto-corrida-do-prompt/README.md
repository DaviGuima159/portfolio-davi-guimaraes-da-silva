# 🧠 Corrida do Prompt — Engenharia de Prompts com Inteligência Artificial

## 📝 Descrição do Projeto

O projeto Corrida do Prompt foi desenvolvido com o objetivo de explorar técnicas de engenharia de prompts aplicadas em Inteligência Artificial generativa.

A atividade consistiu na criação de prompts otimizados para geração de imagens e respostas com maior precisão, qualidade visual e eficiência.

Foram realizados diversos testes envolvendo refinamento de instruções, estruturação de contexto e adaptação de comandos para melhorar os resultados obtidos através de modelos de IA.

---

## 🚀 Tecnologias Utilizadas

- ChatGPT
- Inteligência Artificial Generativa
- Engenharia de Prompts
- Ferramentas de geração de imagem

---

## 📊 Resultados e Aprendizados

- Aprendizado sobre estruturação de prompts
- Melhoria na comunicação com modelos de IA
- Desenvolvimento de pensamento analítico
- Aprimoramento da criatividade
- Exploração de técnicas de refinamento textual
